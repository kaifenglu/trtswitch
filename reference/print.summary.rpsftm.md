# Print method for summary.rpsftm objects

Prints a detailed summary of a rpsftm fit.

## Usage

``` r
# S3 method for class 'summary.rpsftm'
print(x, digits = max(3L, getOption("digits") - 3L), ...)
```

## Arguments

- x:

  An object of class `summary.rpsftm`.

- digits:

  The number of significant digits to print.

- ...:

  Additional arguments passed to `print.data.frame`.

## Value

The input object, invisibly.
