# Summary method for rpsftm objects

Summarizes the specification, treatment effect estimates, and
diagnostics from a rank-preserving structural failure time model.

## Usage

``` r
# S3 method for class 'rpsftm'
summary(object, ...)
```

## Arguments

- object:

  An object of class `rpsftm`.

- ...:

  Additional arguments passed to or from other methods.

## Value

An object of class `summary.rpsftm` containing the analysis population,
model specification, estimation procedure, treatment effect estimates,
diagnostics, bootstrap summary, and reporting notes.
